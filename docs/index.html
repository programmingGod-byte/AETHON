Aethon: High-Throughput eBPF/AF_XDP Security Plane & TLS Reverse Proxy

A dual-plane network engine written in C++20 for Linux kernels. Ingests raw frames directly from physical NIC queues into user space via AF_XDP zero-copy memory rings, executes cryptographic TLS termination, inspects decrypted payloads against Snort/Suricata rules with Intel Hyperscan, and terminates attacks via in-place hardware TCP RST injection.

Dual-Plane Memory & Execution Topology

Separation of kernel-space packet arbitration and user-space layer-7 state machines.

Build & Run Verification

Commands to compile the eBPF bytecode, initialize interfaces, and run the pipeline.

1. Compile Userspace Binary and eBPF Object
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
2. Setup Virtual Ethernet Pair (192.168.50.1 • 192.168.50.2)
sudo ./veth0.bash
3. Start Aethon Engine on Interface veth0
sudo ./build/src/afxdp_control veth0
4. Execute Multi-Port Functional Test Suite
./tests/run_tests.sh 15
