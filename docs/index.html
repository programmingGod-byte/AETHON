Core Architecture

Engineered for Sub-Microsecond Wire Speed

Dual-plane separation ensures hostile floods never reach Linux user space while deep inspection runs at line rate.

Kernel eBPF / XDP Filtering

Driver-level packet validation executing in nanoseconds. Pinned BPF maps provide O(1) IP blocklists and token-bucket rate limiters that return XDP_DROP before kernel SKB allocation.

AF_XDP Zero-Copy DMA

Direct Memory Access bypassing the Linux network stack. Pre-registered contiguous UMEM frames, fill rings, and Rx/Tx rings pinned per CPU core with zero lock contention.

TLS 1.2/1.3 Termination

High-speed cryptographic engine decrypts and terminates TLS handshakes, authenticates upstream services, and decrypts payloads for deep inspection without latency overhead.

Intel Hyperscan DPI

Massively parallel regex scanning matching thousands of Snort and Suricata signatures simultaneously. Detects SQL injection, Remote Code Execution, and path traversal in single-pass scans.

SNI Multi-Port Reverse Proxy

Extracts Server Name Indication (SNI) hostnames dynamically during the TLS ClientHello phase, routing traffic across backend microservices listening on isolated application ports.

In-Place TCP RST Injection

Upon detecting an attack signature, Aethon constructs and transmits a raw Layer 2/3/4 TCP RST frame directly into the AF_XDP TX ring, immediately terminating attacker sessions on the wire.

Build & Run

Quickstart Guide

Clone, build, configure virtual network interfaces, and run automated multi-port tests.

1. Clone & Build with CMake
git clone https://github.com/programmingGod-byte/Intrusion_Detection.git
cd Intrusion_Detection
mkdir -p build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . -j$(nproc)
2. Initialize Virtual Ethernet Pair (veth0 <-> veth1)
sudo ./veth0.bash
3. Launch Aethon Security Engine
sudo ./build/src/afxdp_control veth0
4. Execute Multi-Port TLS & DPI Test Suite
./tests/run_tests.sh 15
